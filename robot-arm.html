1. Serial manipulators, joints and frames

Why it matters: to make a robot weld a seam or pick up a part, you must turn "put the gripper here" into motor angles, and back again. This page builds that mapping step by step, from simple 2-link arms to a six-joint industrial arm.

A serial robot arm is a chain of rigid links connected by joints. A revolute joint (R) rotates by an angle $\theta$; a prismatic joint (P) slides by a distance $d$. The vector of joint variables $\mathbf q = (q_1,\dots,q_n)$ is the robot's configuration, and $n$ is its number of degrees of freedom (DOF). To position and orient a tool anywhere in 3D you need six: three for position and three for orientation.

Forward kinematics (FK) maps joint variables to the tool pose; inverse kinematics (IK) goes the other way. FK always has exactly one answer; IK may have none, one, several or infinitely many.

2. Rotation matrices

Intuition: attach a little set of x, y, z axes (a frame) to every link. A rotation matrix records which way one frame's axes point when seen from another frame.

The orientation of frame $B$ relative to frame $A$ is a $3\times3$ rotation matrix $R^A_B$ whose columns are $B$'s unit axes written in $A$. It is orthonormal ($R^{\mathsf T}R = I$, $\det R = +1$), so $R^{-1} = R^{\mathsf T}$. The elementary rotations are

$$R_x(\alpha)=\begin{bmatrix}1&0&0\\0&c_\alpha&-s_\alpha\\0&s_\alpha&c_\alpha\end{bmatrix}\quad R_y(\beta)=\begin{bmatrix}c_\beta&0&s_\beta\\0&1&0\\-s_\beta&0&c_\beta\end{bmatrix}\quad R_z(\theta)=\begin{bmatrix}c_\theta&-s_\theta&0\\s_\theta&c_\theta&0\\0&0&1\end{bmatrix}$$

with the shorthand $c_\theta = \cos\theta$, $s_\theta = \sin\theta$, and later $c_{12} = \cos(\theta_1+\theta_2)$.

3. Homogeneous transformations

Rotation and translation are combined into one $4\times4$ matrix so that chains of frames become simple matrix products:

$$T^A_B = \begin{bmatrix} R^A_B & \mathbf p^A_B \\ \mathbf 0^{\mathsf T} & 1\end{bmatrix},\qquad \begin{bmatrix}\mathbf p^A\\1\end{bmatrix} = T^A_B\begin{bmatrix}\mathbf p^B\\1\end{bmatrix},\qquad T^A_C = T^A_B\,T^B_C$$

The inverse is not the plain transpose: $\left(T^A_B\right)^{-1} = \begin{bmatrix} R^{\mathsf T} & -R^{\mathsf T}\mathbf p\\ \mathbf 0^{\mathsf T} & 1\end{bmatrix}$.

4. The Denavit–Hartenberg convention, step by step

Intuition: a general frame-to-frame transform needs six numbers. The Denavit–Hartenberg (DH) recipe places the frames cleverly so that each link needs only four, which is what the editable table under the stage shows.

  1. Number the joints and links. Link 0 is the fixed base; joint $i$ connects link $i-1$ to link $i$.
  2. Assign $z_{i-1}$ along the axis of joint $i$ (the rotation axis for R, the sliding direction for P).
  3. Base frame 0: put the origin anywhere on $z_0$; choose $x_0$ conveniently, $y_0 = z_0\times x_0$.
  4. Origin $o_i$: where the common normal between $z_{i-1}$ and $z_i$ meets $z_i$ (if the axes intersect, at the intersection; if parallel, anywhere convenient on $z_i$).
  5. $x_i$ along that common normal, pointing from $z_{i-1}$ towards $z_i$ (if the axes intersect, $x_i = \pm z_{i-1}\times z_i$). Then $y_i = z_i\times x_i$.
  6. Read the four parameters: $a_i$ = distance from $z_{i-1}$ to $z_i$ along $x_i$; $\alpha_i$ = angle from $z_{i-1}$ to $z_i$ about $x_i$; $d_i$ = distance from $x_{i-1}$ to $x_i$ along $z_{i-1}$; $\theta_i$ = angle from $x_{i-1}$ to $x_i$ about $z_{i-1}$. For a revolute joint $\theta_i$ is variable; for a prismatic joint $d_i$ is.
  7. Tool frame: for the last frame put $z_n$ along the approach direction of the tool.

Each row of the table then gives one link transform:

$$A_i=\mathrm{Rot}_{z,\theta_i}\mathrm{Trans}_{z,d_i}\mathrm{Trans}_{x,a_i}\mathrm{Rot}_{x,\alpha_i}=\begin{bmatrix}c_{\theta_i}&-s_{\theta_i}c_{\alpha_i}&s_{\theta_i}s_{\alpha_i}&a_ic_{\theta_i}\\ s_{\theta_i}&c_{\theta_i}c_{\alpha_i}&-c_{\theta_i}s_{\alpha_i}&a_is_{\theta_i}\\0&s_{\alpha_i}&c_{\alpha_i}&d_i\\0&0&0&1\end{bmatrix}$$

5. Forward kinematics

$$T^0_n(\mathbf q) = A_1(q_1)\,A_2(q_2)\cdots A_n(q_n) = \begin{bmatrix}\mathbf n&\mathbf s&\mathbf a&\mathbf o\\0&0&0&1\end{bmatrix}$$

The last column $\mathbf o$ is the tool position; the columns $\mathbf n,\mathbf s,\mathbf a$ (normal, sliding, approach) are the tool axes. For the 2R planar arm this reduces to

$$x = a_1c_1 + a_2c_{12},\qquad y = a_1s_1 + a_2s_{12},\qquad \phi = \theta_1+\theta_2$$

6. Inverse kinematics of the 2-link arm (law of cosines)

The base, elbow and wrist form a triangle with sides $a_1$, $a_2$ and $r=\sqrt{x^2+y^2}$. The cosine rule on the angle at the elbow ($\pi-\theta_2$) gives

$$\cos\theta_2 = \frac{x^2+y^2-a_1^2-a_2^2}{2a_1a_2} \equiv D$$
$$\theta_2 = \operatorname{atan2}\!\left(\pm\sqrt{1-D^2},\,D\right)$$
$$\theta_1 = \operatorname{atan2}(y,x)-\operatorname{atan2}(a_2s_2,\;a_1+a_2c_2)$$

The $\pm$ gives the two solutions, elbow down ($\theta_2>0$) and elbow up. If $|D|>1$ the point lies outside the annulus $|a_1-a_2|\le r\le a_1+a_2$ and is unreachable. Always use atan2, never atan or acos alone: it returns the correct quadrant.

For the 3R planar arm with tool angle $\phi$, first find the wrist point $(x - a_3\cos\phi,\; y - a_3\sin\phi)$, solve the 2R problem for it, then $\theta_3 = \phi-\theta_1-\theta_2$. The 6-DOF arm with a spherical wrist uses the same idea in 3D (kinematic decoupling): the wrist centre $\mathbf o_c = \mathbf o - d_6\mathbf a$ fixes $\theta_1,\theta_2,\theta_3$, and the wrist angles follow from $R^3_6 = (R^0_3)^{\mathsf T}R$.

7. Velocity kinematics: the Jacobian

Intuition: if each joint turns a little, how fast and in which direction does the tool move? The Jacobian $J$ is the table of those sensitivities. The Jacobian maps joint rates $\dot{\mathbf q}$ (joint speeds) to the tool's linear velocity $\mathbf v$ and angular velocity $\boldsymbol\omega$, $\begin{bmatrix}\mathbf v\\ \boldsymbol\omega\end{bmatrix} = J(\mathbf q)\,\dot{\mathbf q}$. Column $i$ of the geometric Jacobian is built from frame $i-1$ (all read from the $T^0_{i-1}$ matrices):

$$J_i = \begin{bmatrix} \mathbf z_{i-1}\times(\mathbf o_n-\mathbf o_{i-1})\\ \mathbf z_{i-1}\end{bmatrix}\ \text{(revolute)},\qquad J_i = \begin{bmatrix}\mathbf z_{i-1}\\ \mathbf 0\end{bmatrix}\ \text{(prismatic)}$$

For the 2R arm (position rows only):

$$J = \begin{bmatrix}-a_1s_1-a_2s_{12} & -a_2s_{12}\\ a_1c_1+a_2c_{12} & a_2c_{12}\end{bmatrix},\qquad \det J = a_1a_2\sin\theta_2$$

The same matrix relates forces: joint torques needed to push with tool wrench $\mathbf F$ are $\boldsymbol\tau = J^{\mathsf T}\mathbf F$.

8. Singularities

Where the (task) Jacobian loses rank, $\det J = 0$, the arm cannot move its tool in some direction no matter how fast the joints turn, and the IK needs infinite joint speeds nearby. The manipulability $w=\sqrt{\det(JJ^{\mathsf T})}$ measures how far you are from one; the ellipse drawn at the planar tool shows the velocities reachable with unit joint speeds. Types:

  • Boundary singularities: arm fully stretched or folded ($\theta_2 = 0$ or $\pi$ in the 2R arm), at the edge of the workspace.
  • Interior singularities: e.g. the wrist centre on the base axis $z_0$ of the 6-DOF arm (shoulder singularity).
  • Wrist singularity: $\theta_5 = 0$ aligns joint axes 4 and 6, so only their sum matters.

9. Numerical inverse kinematics

For general robots IK is solved iteratively. With task error $\mathbf e$ (position error, plus orientation error $\tfrac12\sum(\mathbf n\times\mathbf n_d+\mathbf s\times\mathbf s_d+\mathbf a\times\mathbf a_d)$ if orientation is controlled), repeat

$$\Delta\mathbf q = J^{\mathsf T}\left(JJ^{\mathsf T}+\lambda^2 I\right)^{-1}\mathbf e,\qquad \mathbf q \leftarrow \mathbf q + \Delta\mathbf q$$

This damped least squares (Levenberg–Marquardt) step behaves like the pseudo-inverse far from singularities and stays bounded near them. Larger $\lambda$ is more robust but slower and less accurate. Try both solvers in IK mode, and push the target outside the workspace: the DLS arm reaches towards it smoothly instead of failing.

10. Trajectory planning

A path is the geometry; a trajectory adds timing. Between pose A and pose B we interpolate with a time-scaling function $s(\tau)$, $\tau = t/T$:

$$\text{cubic: } s = 3\tau^2-2\tau^3,\qquad \text{quintic: } s=10\tau^3-15\tau^4+6\tau^5$$

The cubic satisfies zero velocity at both ends; the quintic also has zero acceleration at both ends (no jump in motor torque, gentler on gearboxes). Peak velocity is $1.5\,\Delta/T$ for the cubic and $1.875\,\Delta/T$ for the quintic.

  • Joint-space interpolation $\mathbf q(t) = \mathbf q_A + s(\tau)(\mathbf q_B-\mathbf q_A)$: simple, no IK needed, never meets a singularity on the way, but the tool follows a curve.
  • Cartesian interpolation $\mathbf p(t) = \mathbf p_A + s(\tau)(\mathbf p_B-\mathbf p_A)$ with IK at every sample: the tool moves in a straight line (needed for welding, inserting, picking), but joint speeds blow up near singularities.
Model limits. This is pure kinematics: no masses, motor limits, dynamics or collisions between links are modelled. The 6-DOF arm is an idealised elbow manipulator with a spherical wrist (zero shoulder and elbow offsets, unlike a real PUMA 560).

Example 1: forward kinematics of the 2R arm

$a_1 = 0.40$ m, $a_2 = 0.30$ m, $\theta_1 = 30°$, $\theta_2 = 45°$ (the 2R default).

  1. $c_1 = 0.8660$, $s_1 = 0.5000$, $\theta_1+\theta_2 = 75°$: $c_{12} = 0.2588$, $s_{12} = 0.9659$.
  2. $A_1 = \begin{bmatrix}0.866&-0.5&0&0.346\\0.5&0.866&0&0.2\\0&0&1&0\\0&0&0&1\end{bmatrix}$, $A_2 = \begin{bmatrix}0.707&-0.707&0&0.212\\0.707&0.707&0&0.212\\0&0&1&0\\0&0&0&1\end{bmatrix}$.
  3. $x = 0.4(0.8660) + 0.3(0.2588) = 0.3464 + 0.0776 = 0.4241$ m.
  4. $y = 0.4(0.5000) + 0.3(0.9659) = 0.2000 + 0.2898 = 0.4898$ m; tool angle $\phi = 75°$.

Example 2: inverse kinematics, both elbows

Same arm, target $(x, y) = (0.50, 0.20)$ m.

  1. $r^2 = 0.25 + 0.04 = 0.29$. $D = (0.29 - 0.16 - 0.09)/(2\times0.4\times0.3) = 0.04/0.24 = 0.1667$. $|D| \le 1$: reachable.
  2. Elbow down: $\theta_2 = \operatorname{atan2}(+0.9860, 0.1667) = 80.41°$. Elbow up: $\theta_2 = -80.41°$.
  3. $\operatorname{atan2}(0.2, 0.5) = 21.80°$. For elbow down, $\operatorname{atan2}(0.3\times0.9860,\ 0.4 + 0.3\times0.1667) = \operatorname{atan2}(0.2958, 0.45) = 33.32°$, so $\theta_1 = -11.52°$.
  4. For elbow up the second atan2 is $-33.32°$, so $\theta_1 = 55.12°$. Check: $0.4\cos55.12° + 0.3\cos(-25.29°) = 0.2287 + 0.2713 = 0.500$ ✓.

Example 3: Jacobian and singularity

At $\theta = (30°, 45°)$:

  1. $J_{11} = -0.4(0.5) - 0.3(0.9659) = -0.4898$, $J_{12} = -0.2898$, $J_{21} = 0.4(0.866) + 0.3(0.2588) = 0.4241$, $J_{22} = 0.0776$.
  2. $\det J = (-0.4898)(0.0776) - (-0.2898)(0.4241) = 0.0849$, which equals $a_1a_2\sin\theta_2 = 0.12\sin45° = 0.0849$ ✓.
  3. Joint rates for a tool velocity of $(0, 0.1)$ m/s: $\dot{\boldsymbol\theta} = J^{-1}\mathbf v = \frac{1}{0.0849}\begin{bmatrix}0.0776&0.2898\\-0.4241&-0.4898\end{bmatrix}\begin{bmatrix}0\\0.1\end{bmatrix} = \begin{bmatrix}0.341\\-0.577\end{bmatrix}$ rad/s.
  4. As $\theta_2\to0$ (arm straight) $\det J\to0$ and these rates grow without bound: a boundary singularity.

Example 4: SCARA forward kinematics

$a_1 = 0.35$, $a_2 = 0.30$, $d_1 = 0.40$, $d_4 = 0.08$ m; $\theta_1 = 20°$, $\theta_2 = 40°$, $d_3 = 0.15$ m, $\theta_4 = 10°$ (the SCARA default).

  1. $x = 0.35\cos20° + 0.3\cos60° = 0.3289 + 0.1500 = 0.4789$ m.
  2. $y = 0.35\sin20° + 0.3\sin60° = 0.1197 + 0.2598 = 0.3795$ m.
  3. $z = d_1 - d_3 - d_4 = 0.40 - 0.15 - 0.08 = 0.17$ m. The $\alpha_2 = 180°$ row flips $z$, so the tool points down.
  4. Tool yaw $\psi = \theta_1+\theta_2-\theta_4 = 50°$: $R = \begin{bmatrix}c_\psi&s_\psi&0\\s_\psi&-c_\psi&0\\0&0&-1\end{bmatrix} = \begin{bmatrix}0.643&0.766&0\\0.766&-0.643&0\\0&0&-1\end{bmatrix}$.

Example 5: cubic vs quintic time scaling

A joint moves from 0° to 90° in $T = 2$ s.

  1. Cubic: $\theta(t) = 90(3\tau^2-2\tau^3)$, $\dot\theta = \tfrac{90}{2}(6\tau-6\tau^2)$. Peak at $\tau = 0.5$: $1.5\times90/2 = 67.5$ °/s. Acceleration jumps to $6\times90/4 = 135$ °/s² at $t = 0$.
  2. Quintic: peak velocity $1.875\times90/2 = 84.4$ °/s; acceleration starts at zero and peaks at $\tfrac{10}{\sqrt3}\times\tfrac{90}{4} \approx 129.9$ °/s² at $\tau \approx 0.211$.
  3. Run both in Trajectory mode and compare the velocity plots: the quintic starts with zero slope.
